README

发表于2026-10-25|更新于2026-10-25
|浏览量:

这是一个README，主要写一下一些碎碎念。

这个blog用了hexo和butterfly主题，发在GitHub Pages上，好像建成在2026/10/15还是16号来着，得手动更新（应该会每天更，但每周一定更）。每篇笔记使用HTML语言这个好像不算编程语言编写。

这个blog还在慢慢建设，暂时不会变了，以后可能还会有更多功能应该吧。

这个blog主要是用来放一些学习笔记，一些解题记录什么的，每篇笔记在新学到相关的东西的话可能还会再更新，不只是ctf，主要是计算机，编程语言，ctf之类的。

先避雷，记笔记不能占用太多时间，学东西才是重点，所以笔记中的一些基础和排版会使用ai，确保内容得我复习时能看懂，盯着电脑敲三四个小时改来改去再不满意删了真是太痛苦了太浪费时间了😢但是一些实操比如做题啊则会手动复现并配截图。

每周都会有周报，周报会汇报了这周干了什么（当然只有跟ctf有关的），周报不会使用ai，我会尽量做到以下几点：

  • 写出这周学了什么知识，做了那些题。
  • 排版整洁清楚，减少雷霆错字。
  • 语言尽量干净明白，让人能看懂，减少废话。
  • 用心整理，但不在上面浪费太多时间。
  • 学的知识要自己的话复述一遍，做题要有思考过程

应该就这些了，能从这个README看出来，我写的东西挺烧心的毕竟语文水平就这样但我相信，写多了就会练出来，逐渐找到自己的风格的。好好学习天天向上吧。

标准结尾，我也不会写别的啊，光这些我就写了半个小时啊😢😢😢。
